# Склад — приёмка по 2D/QR-скану

Веб-приложение для приёмки и списания товара сканером. Скан сразу попадает в раздел «Склад»: никуда кликать не нужно, поле очищается само и ждёт следующий товар.

## Как работает

- **Приёмка**: большое поле скана держит курсор у себя. Сканер «печатает» код и жмёт Enter, после чего приложение:
  1. разбирает код (`js/parse.js` → `parseScan`);
  2. находит товар по артикулу или создаёт новый;
  3. прибавляет количество (режим «Приход») или списывает его (режим «Расход»);
  4. очищает поле, пищит и показывает результат.
- **Скан принимается с любой вкладки и из любого поля.** Если курсор стоит, например, в поиске, приложение распознаёт быстрый поток символов от сканера, возвращает полю прежний текст и обрабатывает код как скан.
- **Режимы**: Приход `+`, Расход `−`, Проверка (показывает, что прислал сканер и что вернул `parseScan`, склад при этом не меняется).
- **Кол-во**: сколько единиц учесть одним сканом. После каждого скана поле возвращается к 1.
- **Склад**: остатки, поиск, сортировка, правка названия и корректировка остатка, экспорт в CSV для Excel.
- **Журнал**: все движения. Отмена операции не удаляет запись, а добавляет обратную, поэтому история сходится.
- Повторное считывание того же кода быстрее 0,4 с считается «дребезгом» сканера и пропускается.

## Настройка сканера

- Режим **USB HID / клавиатура** (у большинства сканеров включён по умолчанию).
- Суффикс после кода: **Enter** (CR). Tab тоже поддерживается.
- Если при русской раскладке Windows вместо `ART-001` приходит `ФКЕ-001`, включите «Исправлять раскладку» в настройках (включено по умолчанию).
- Bluetooth-сканер «теряет» коды, когда курсор не в поле скана? Увеличьте в настройках «макс. паузу между символами» до 80–120 мс.

## Коды и названия

Штрихкод производителя (EAN-13 и т.п.) содержит только номер товара, без названия. Первые цифры — страна регистрации (`487` — Казахстан, `478` — Узбекистан, `460–469` — Россия). Название приложение берёт так:

1. **Справочник** («Склад» → «Справочник»): загрузите Excel/CSV со штрихкодами и названиями — выгрузку из 1С, накладную, прайс. Колонки определяются сами (их можно поправить), кодировка старой 1С (windows-1251) читается, несколько штрихкодов в одной ячейке разделяются.
2. **Окно «Новый товар»**: если кода нет ни на складе, ни в справочнике, после скана сразу открывается окно для названия. Можно не нажимать «Сохранить» и сканировать дальше — введённое сохранится. Отключается в настройках.
3. Название, заданное вручную, тоже запоминается в справочнике.

Разбор кода — `parseScan(raw)` в `js/parse.js`:

- штрихкоды EAN-8 / UPC-A / EAN-13 / GTIN-14 проверяются по контрольной цифре: криво считанный код не создаст лишний товар;
- случайные символы по краям (например, `'` от нечаянно нажатой «Э») отбрасываются;
- UPC-A (12 цифр) и GTIN-14 с ведущим нулём приводятся к EAN-13 — один товар не раздвоится;
- свои коды (артикулы, QR) берутся как есть.

Проверить, что пришло от сканера и как оно разобралось, можно в режиме «Проверка».

## Данные

Данные хранятся в `localStorage` браузера (склад — `sklad.v1`, справочник — `sklad.catalog.v1`) и не синхронизируются между устройствами. Резервная копия (JSON) скачивается и восстанавливается в настройках. Журнал хранит последние 5000 операций, остатки от этого лимита не зависят.

## Обновление

После правок в `js/` или `css/` увеличьте `?v=N` у подключений в `index.html` — иначе браузер может показать старую версию из кэша.

## Запуск

Сборка не нужна: откройте `index.html` или запустите любой статический сервер:

```bash
python -m http.server 8770
```

## Файлы

| Файл | Что внутри |
|---|---|
| `js/scanner.js` | Приём скана: поле, глобальный перехват, исправление раскладки |
| `js/parse.js` | Разбор кода (`parseScan`), проверка штрихкодов EAN/UPC |
| `js/store.js` | Товары, журнал, справочник, настройки, резервная копия |
| `js/catalog.js` | Чтение справочника из Excel/CSV, поиск колонок |
| `js/app.js` | Интерфейс: вкладки, отрисовка, звук, экспорт |
